# Задание 5. Разработка cutover-плана

## Выбор стратегии миграции

Поскольку как таковой системы нет, а есть только ручные процессы с файлами Excel, нет необходимости в параллельном запуске двух систем или в постепенном переносе функциональности. Выбрана стратегия High Level Design:
- проектирование с учётом домена, 
- определение модульных границ.

Я не вижу каких-либо ограничений, система будет построена с нуля, нужно будет только реализовать миграцию данных из файлов с БД и обучить персонал работе с системой. Обучение можно провести на тестовых данных.
